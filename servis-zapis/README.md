# Generátor BOZP protokolu

Otvorte `index.html` v modernom prehliadači. Vyplňte údaje, upravte alebo doplňte zistenia a stlačte **Stiahnuť PDF**. Otvorí sa dialóg pre tlač; v ňom zvoľte **Uložiť ako PDF**.

Aplikácia funguje bez servera. Rozpracovaný protokol sa uloží len do lokálneho úložiska prehliadača. Pred zmazaním údajov prehliadača použite možnosť **Stiahnuť rozpracované (.json)**.

Šablóna vychádza zo štruktúry protokolu z kontroly BOZP depa Žilina. Text každého zistenia treba pred odoslaním doplniť a vecne overiť pre konkrétnu kontrolu.
