# Odboráčik

Zdrojový statický web. Úplný návod na GitHub automatizáciu, prijímač dotazov a evidenciu je v `../README.md`. Odpovede sú v `knowledge-base.js`. `config.js` obsahuje len verejné nastavenia; verejné lokálne ukladanie je vypnuté. GitHub Actions z premenných automaticky vytvorí konfiguráciu pre nasadenie.
